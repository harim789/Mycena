---
description: Mycena용으로 프로젝트의 기존 파일 전체에 쉬운 설명을 붙입니다
---

프로젝트의 소스 파일들을 훑어보고, 관계 그래프에서 파일을 클릭했을 때 보여줄 설명을 `.mycena/descriptions.json`에 작성해 주세요.

규칙
- 키는 프로젝트 루트 기준 상대경로(예: `src/main/java/com/app/service/UserService.java`)입니다.
- 설명은 개발 입문자도 30초 안에 이해할 수 있는 쉬운 한국어로, 필요하면 일상 비유를 씁니다.
- 이미 파일이 있으면 기존 내용을 유지하면서 빠진 파일만 추가하거나 틀린 설명을 고칩니다.
- 빌드 산출물, 라이브러리, 자동 생성 파일은 건너뜁니다.
- 코드는 수정하지 마세요. 이 작업은 설명 파일만 만듭니다.

형식
```json
{
  "src/.../UserService.java": {
    "summary": "한 줄 요약 (이 파일이 하는 일)",
    "detail": "2~3문장 설명. 어떤 흐름에서 쓰이는지, 비유가 있으면 함께.",
    "concepts": ["회원 관리", "JWT 인증"],
    "uses": [{ "path": "src/.../UserRepository.java", "why": "회원 정보를 DB에서 찾기 위해" }]
  }
}
```

`concepts`는 프로젝트 전체에서 같은 이름을 재사용해 주세요(그래프에서 같은 개념 노드로 묶입니다). $ARGUMENTS
